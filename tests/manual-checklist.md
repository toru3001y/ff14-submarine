# 手動確認チェックリスト（SPEC §8.4）

リリース前に実行する。**E2E（Playwright等）は導入せず、本チェックリストを正式な受け入れ条件とする。**
レイアウトの成立・フォントの描画・フォーカスリングの視認性は実ブラウザでの視覚判断が主であり、
スクリーンショット照合で機械化すると環境差による偽陽性が多く、維持コストが検証価値を上回るため。

## 合格基準

**「ぱっと見で崩れておらず、操作・判読できる」こと**（SPEC §5.5.2）。

**検証しないもの**: 数px単位の位置、余白の厳密な一致、文字幅、桁位置、
特定のOSフォント名で描画されたか、合成ボールド、スクリーンショットのピクセル一致。

## 実施方法

```
npm run build
npx vite preview
```

開発中の確認は `npx vite` でもよい。対応環境は **PC・ビューポート幅 960px 以上**（SPEC §1）。
960px 未満は対応対象外のため確認しない。

## チェック項目

### レイアウト

- [ ] 幅 **960 / 1040 / 1440 px** で主要要素が重ならない
- [ ] 意図しない横スクロールが発生しない
- [ ] 文字や数値が表示領域から切れない（**下の「値域の確認手順」**で最大値・最小値を表示して確認する）
- [ ] 総合ステータスとキャパシティ超過警告が判読でき、他の操作要素に重ならない
- [ ] モックアップ「2c 松葉」（`old/ui-design/`）と全体的な雰囲気が大きく異ならない

### 操作

- [ ] ランク入力・4つのパーツ選択・リセットが操作できる
- [ ] **Tab のフォーカス移動順が、画面上の視覚的な並び順と一致する**（jsdom では検証不能なため必須）
      期待順: ランク入力 → 艦体 → 艦尾 → 艦首 → 艦橋 → 選択をリセット
- [ ] Tab でフォーカスを移動したとき、全操作要素でフォーカスリングが視認できる
- [ ] ランク入力欄で ↑↓ キーを押してもページがスクロールしない

### 表示・判読

- [ ] **日本語・数字・記号・ユーザー入力が判読でき、文字化けや豆腐（□）が発生していない**
      記号: `—`（U+2014）、`⚠`、`+` / `-`
- [ ] グレースケール表示でも正の値と負の値を区別できる（符号による識別。SPEC §5.1.1、§6 A7）
      OS またはブラウザ拡張でグレースケール表示にして確認する

## 値域の確認手順

SPEC §4.3 の「画面表示の値域」を実際に表示させる。以下は実データから算出した組み合わせで、
各ステータスの理論上の最大値・最小値をちょうど作れる。

### 最大値（ランク **135**）

| 確認する値 | 期待値 | 艦体 | 艦尾 | 艦首 | 艦橋 |
|---|---|---|---|---|---|
| 探査 | **290** | シーラカンス級 | ウンキウ改級 | シーラカンス改級 | シーラカンス改級 |
| 収集 | **365**（最大桁） | シルドラ改級 | シルドラ級 | ホエール改級 | ホエール改級 |
| 巡航 | **260** | ホエール改級 | シャーク改級 | ウンキウ改級 | シーラカンス級 |
| 航続 | **335** | ウンキウ改級 | ホエール改級 | シルドラ級 | ホエール改級 |
| 運 | **265** | シャーク改級 | ウンキウ改級 | シルドラ級 | シルドラ級 |

### 最小値（ランク **1**。ランクボーナスが 0 のため）

| 確認する値 | 期待値 | 選択するパーツ（他の部位は未選択のまま） |
|---|---|---|
| 探査 | **-45** | 艦体=ホエール級、艦尾=シャーク級 |
| 収集 | **-10** | 艦体=シーラカンス級 |
| 巡航 | **-20** | 艦首=ホエール級、艦橋=シルドラ級 |
| 航続 | **-65**（最小） | 艦体=シルドラ級、艦尾=シルドラ級、艦首=シャーク級、艦橋=シーラカンス級 |
| 運 | **0** | （負の値を持つパーツが存在しないため、全未選択で 0） |

### コストと超過警告

| 確認内容 | 手順 | 期待 |
|---|---|---|
| コスト最大 | 4部位すべて **シャーク改級**（各20） | `80` |
| 超過警告 | ランク **1** ＋ 艦体=シャーク改級(20) ＋ 艦尾=シャーク級(5) | コスト `25 / 20` が赤、`⚠ キャパシティを 5 超過` |
| 超過しない | 上と同じ選択でランクを **50** 以上にする | 警告が消える |

> **補足**: パーツコスト合計の最大は 80、ランク50以降のキャパシティは 80 で固定である。
> `80 > 80` は偽であるため、**キャパシティ超過はランク1〜49でのみ発生し得る**（SPEC §3.4）。

### エラー表示

| 入力 | 期待 |
|---|---|
| `12a` | `ランクは数字のみで入力してください` |
| `0` / `136` | `ランクは1〜135の範囲で入力してください` |
| `１３５`（全角） | エラーなし。フォーカスを外すと `135` に整形される |
| `01` | エラーなし。フォーカスを外すと `1` に整形される |

- [ ] エラーの表示・非表示でレイアウトが上下に跳ねない
- [ ] 超過警告の表示・非表示でレイアウトが上下に跳ねない
